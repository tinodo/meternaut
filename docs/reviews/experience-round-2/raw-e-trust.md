# Cold-Reader Review: `08-attention-and-trust.md` and `11-access-language-inclusion.md`

## 1. Verdict

**Mostly.** The attention-budget model, four-layer AI disclosure, and WCAG 2.2 AA page architecture give an adopter a clear, humane foundation to build from. However, contradictions between the prose and the 17 Adaptive Card templates—including hiding `"Talk to a person"` inside collapsed containers, penalising out-of-hours approvals by alerting the platform team, and an inconsistent push-budget and coverage-routing state machine—must be fixed before implementation.

## 4. Fact checks

1. **Claim (`08-attention-and-trust.md:100, 103`):** Teams provides a platform `"AI Generated"` label per message (`addAiGenerated()`), and the linked page documents both the label and Teams' thumbs feedback per message.
   - **URL:** `https://learn.microsoft.com/en-us/microsoftteams/platform/agents-in-teams/integrate-ai/ai-content-labels`
   - **Result:** **Partially supported.** The page confirms `AddAIGenerated()` / `add_ai_generated()` / `addAiGenerated()` displays the **AI Generated** label in personal, group, and channel chats (including GCC, GCC High, DoD) and supports Adaptive Cards, but does not document Teams' thumbs feedback controls.
2. **Claim (`11-access-language-inclusion.md:20–21, 114`):** Adaptive Card accessibility relies on `style: "heading"`, `label` over `placeholder`, `errorMessage`, `tooltip` on `Action.ToggleVisibility`, no hidden inputs, and testing with Narrator/NVDA in Teams.
   - **URL:** `https://learn.microsoft.com/en-us/microsoft-copilot-studio/adaptive-card-accessibility-tips`
   - **Result:** **Verified on Learn, but violated in `cards\recommendation.json`.** Learn confirms each property and Narrator/NVDA testing, but warns against `isVisible: false` (screen readers skip hidden elements) and multi-column `ColumnSet` tab order—both used in `recommendation.json`.
3. **Claim (`11-access-language-inclusion.md:103`):** Microsoft Entra's built-in phishing-resistant MFA strength accepts a FIDO2 security key, a platform credential such as Windows Hello for Business, and a certificate.
   - **URL:** `https://learn.microsoft.com/en-us/entra/identity/authentication/concept-authentication-strengths`
   - **Result:** **Mostly accurate, with two omissions.** Learn requires **Certificate-based authentication (multifactor)** (excluding single-factor certificates) and notes that users who signed in with a password are not prompted in-session for Windows Hello step-up and must restart via **Sign-in options**.
4. **Claim (`11-access-language-inclusion.md:45`):** Microsoft Graph's JSON `sendMail` takes one body, whereas MIME format (`text/plain` with base64 RFC 2045 content) carries both `text/plain` and `text/html`.
   - **URL:** `https://learn.microsoft.com/en-us/graph/api/user-sendmail`
   - **Result:** **Verified.** JSON `sendMail` takes a single `message.body` (`itemBody`), while MIME `sendMail` accepts base64 RFC 2045 `multipart/alternative` content.
5. **Claim (`08-attention-and-trust.md:179`):** Microsoft's supervision pattern for agent requests offers **Approve**, **Reject** (with an optional reason), and **Suggest an alternative**.
   - **URL:** `https://learn.microsoft.com/en-us/security/agentic-security/agentic-security-supervise-work`
   - **Result:** **Verified.** The article documents those exact three response options for sessions in the **Waiting for input** state.

## 5. Questions left unanswered

1. **How does `"Fewer like this"` (`08-attention-and-trust.md:118`) work in code?** By how much does it lower frequency, what scope or recipe category does it suppress, and when does that suppression expire?
2. **Which card or message is sent at day 14 when an item is parked (`08-attention-and-trust.md:62`) or routed to cover (`08-attention-and-trust.md:64`)?** Neither exists in `docs\experience\cards\manifest.json`.
3. **How does MIME e-mail sending (`11-access-language-inclusion.md:45`) work without resolving the recipient's e-mail address (`08-attention-and-trust.md:201`)?** RFC 5322 MIME requires a `To:` address header; the doc should state that the address is resolved live from Entra ID by `objectId` at send time without persisting it.
4. **What happens on `Hello` (`C1`) and `Settings` (`C14`) when a user selects `"Another time zone: I will ask on the page"` or `"I will set it on the page"` and taps `"Save"`?** Since `Action.Execute` cannot open a browser tab, does the bot reply with a link card?
5. **How can an owner permanently decline a Recommendation (`C3`) in Teams?** `cards\recommendation.json` offers `"Review the plan"`, `"Not now"`, and `"Not mine"`, but no `"Decline"` button.
