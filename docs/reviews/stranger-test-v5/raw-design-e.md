## 4. Fact checks

1. **"[Azure Copilot Optimization agent](...)" is VM/VMSS-only, no documented API, reached via Azure Copilot chat or Advisor's Optimize button (08: the baselines table).** Checked `learn.microsoft.com/azure/copilot/optimization-agent` (updated 2026-08-10). Confirmed: resource types listed are exactly "Virtual machines (VMs)" and "Virtual Machine Scale Sets (VMSS)"; access is via the Azure Copilot chat pane or the Advisor cost-recommendations page's Optimize button; no REST/API surface is documented on this page. **Result: accurate.**
2. **"Flex processing costs half the Standard token price" (08:179, repeated 10).** Checked `learn.microsoft.com/azure/foundry/openai/how-to/flex-processing` (updated 2026-10-12): "Flex processing (preview) provides inference at a 50% discount compared with Standard processing." **Result: accurate, exact match.**
3. **AI Search Basic unit price, Sweden Central, feeding the 64.88 EUR/month Pilot line (10:24; `cost/meters-used.md`: 0.088877 EUR/hour).** Queried the live Azure Retail Prices API directly (`prices.azure.com/api/retail/prices`, filtered to `swedencentral`/`Azure Cognitive Search`/`Basic`): current live price is 0.0907 EUR/hour. The design's snapshot (dated 2026-10-31) is about 2% lower — consistent with Azure's monthly EUR exchange-rate refresh, not an error. **Result: plausible; right order of magnitude and right meter, small expected drift.**
4. **The reservation "calculate" call "prices an order without placing it" (08: the action-plane test table, "Unknown outcome" row).** Checked `learn.microsoft.com/rest/api/reserved-vm-instances/reservation-order/calculate` (updated 2026-08-04): "Calculate price for placing a ReservationOrder" — a distinct, non-mutating endpoint from actually placing one. **Result: accurate.**
5. **AI Red Teaming Agent: builds on PyRIT and Foundry's safety evaluators; cloud runs exclude workflow agents and function tool calls; single-turn, English only (08: "What the AI Red Teaming Agent covers").** Checked `learn.microsoft.com/azure/foundry/concepts/ai-red-teaming-agent` (updated 2026-08-27): confirmed it "leverages… PyRIT… along with Microsoft Foundry's Risk and Safety Evaluations." Did **not** locate the agent-type/turn/language limits in the portion fetched. **Result: general framing verified; granular scope claims plausible but unverified — stated, not guessed.**
