## 4. Fact checks

Checked on Microsoft Learn, 2026-11-01. Result is confirmed, partial, or wrong.

1. **Supported and unsupported offers** (`14:22`). Confirmed. Dev/Test, Visual Studio and Free Trial are supported; EA sponsorship, Azure for Students, Azure for Students Starter and classic CSP are not. https://learn.microsoft.com/azure/cost-management-billing/costs/understand-cost-mgt-data
2. **Quota id pairs with one agreement** (`14:63`). Wrong. See finding 1. Same URL, footnote 3: "Quota IDs are the same across Microsoft Customer Agreement and classic subscription offers." Subscriptions Get was not fetched; the collision is on the table this sentence cites.
3. **EA subscription costs need Cost Management Reader and "account owners can view charges"** (`14:17`). Confirmed for subscription scope. Department scope needs "DA view charges", which this row correctly does not claim. https://learn.microsoft.com/azure/cost-management-billing/costs/assign-access-acm-data
4. **MCA needs Cost Management Reader and the billing profile "Azure charges" setting, changed by a billing profile owner** (`14:18`). Confirmed. Same URL.
5. **Partner cost visibility is off until the partner enables it; the customer sees retail rates** (`14:19`). Confirmed. "Unless enabled by a partner, the cost visibility policy is disabled." Customers see pay-as-you-go retail rates. "without the partner's discounts or credits" is a fair reading of retail versus invoiced, not those words. https://learn.microsoft.com/azure/cost-management-billing/costs/get-started-partners
6. **Management groups are a cost scope for EA and pay-as-you-go, not MCA or partner** (`14:22`). Confirmed for MCA: "Management groups aren't currently supported in Cost Management features for Microsoft Customer Agreement subscriptions." Partner-sold Azure plans are MCA subscriptions; there is no separate partner sentence. https://learn.microsoft.com/azure/cost-management-billing/costs/understand-work-scopes
7. **A billing role shows costs but not resources** (`14:26`). Confirmed. Same URL.
8. **Cross-tenant Cost Management access is limited** (`14:145`). Confirmed. https://learn.microsoft.com/azure/cost-management-billing/costs/assign-access-acm-data
9. **Exports: FOCUS, actual and amortized for EA and MCA, including partner, at billing, subscription and resource group** (`14:42`). Confirmed by the tutorial's dataset matrix. Pay-as-you-go is absent. https://learn.microsoft.com/azure/cost-management-billing/costs/tutorial-improved-exports
10. **Pay-as-you-go does not support FOCUS** (`14:42`, `05:62`). Confirmed. Limitations: "Azure MOSP billing scopes and subscriptions don't support FOCUS datasets." The "probe decides" clause is not supported. Same URL.
11. **Management-group exports are usage CSV only** (`14:42`). Confirmed. "Only the cost and usage details (Usage) dataset is available in CSV format without any compression." Same URL.
12. **Rerunning an export reaches 13 months** (`14:42`). Partial. Portal "Export selected dates" is 13 months, one month at a time. The same page's FAQ says the Exports Execute REST API can retrieve cost and usage for up to 7 years. An automated ingester should not treat 13 months as the platform ceiling.
13. **Export role is Owner or Contributor** (`14:42`, `05:60`). Wrong as a requirement. Scopes matrix: Cost Management Contributor can create exports; Cost Management Reader cannot. https://learn.microsoft.com/azure/cost-management-billing/costs/understand-work-scopes
14. **Cost Details: EA and MCA only, not management groups; one month; 13 months back; refresh every four hours; above 2 GB use exports** (`14:43`). Confirmed. "Call at most daily" is a recommendation ("we recommend"), not a hard ban. "Cost Management Reader" is sufficient, not exclusive: the scopes matrix also lists Reader as read on that API, while assign-access still says Cost Management Reader. https://learn.microsoft.com/azure/cost-management-billing/automate/get-small-usage-datasets-on-demand
15. **Usage Details API: pay-as-you-go, MSDN, Visual Studio; deprecation planned, no date** (`14:44`). Confirmed. "The exact date of deprecation is still being determined." A different EA reporting API on `consumption.azure.com` is already retired; this sentence points at the right API. https://learn.microsoft.com/azure/cost-management-billing/automate/migrate-consumption-usage-details-api
16. **Query API: aggregates, two group-bys, 12/60/600 query units, one per month; management groups and partner customer scope** (`14:45`, `05:85`). Confirmed. "Query can have up to 2 group by clauses" (API version shown: 2026-06-01). QPU quotas match. A `CustomerQuery-MCA` example exists. The management-group example is labeled Legacy, which fits "not for MCA". https://learn.microsoft.com/rest/api/cost-management/query/usage and https://learn.microsoft.com/azure/cost-management-billing/costs/manage-automation
17. **`AccountCostDisabled` means EA view-charges is off** (`14:65`). Confirmed. MCA 401 does not name the Azure charges setting. See finding 4. https://learn.microsoft.com/azure/cost-management-billing/costs/cost-management-error-codes
18. **FOCUS columns `ContractedUnitPrice`, `x_BilledUnitPrice`, `x_EffectiveUnitPrice`; commitment discounts are in `EffectiveCost`, not `ContractedUnitPrice`** (`14:49`–`14:51`). Confirmed. `ContractedUnitPrice` excludes commitment-based discounts. https://learn.microsoft.com/azure/cost-management-billing/dataset-schema/cost-usage-details-focus
19. **FOCUS 1.0, with 1.2 in preview** (`05:62`). Confirmed. That schema page still has a "Version 1.2-preview" section.
20. **Retail Prices API: no sign-in, undiscounted, 1,000 rows a page, savings-plan rates only in `2023-01-01-preview`, USD base** (`14:53`, `05:87`). Confirmed. https://learn.microsoft.com/rest/api/cost-management/retail-prices/azure-retail-prices
21. **Data lands in 8–24 hours on EA/MCA and up to 72 on pay-as-you-go; a period closes within 72 hours; charges can change until about day five** (`05:64`, `14:47`). Partial. The page says "typically" 8–24 hours and "could take" up to 72. Day five and the 72-hour close are stated. The design drops "typically". https://learn.microsoft.com/azure/cost-management-billing/costs/understand-cost-mgt-data
22. **Azure re-exports the previous month on each of the first five days** (`05:64`). Confirmed. Two runs a day for the first five days; the second writes the prior month so the file matches the invoice. https://learn.microsoft.com/azure/cost-management-billing/costs/tutorial-improved-exports
23. **Cost Management omits tax, credits and support** (`05:83`). Confirmed. Same data page, included/not-included table.
24. **Reservation purchase: Owner or Reservation Purchaser; custom role cannot buy; EA policy can limit to admins; MCA billing profile owner can restrict, but billing profile and billing account owners can always buy** (`14:98`, `14:102`). Confirmed. https://learn.microsoft.com/azure/cost-management-billing/reservations/prepare-buy-reservation
25. **Partner reservation and savings-plan self-service is off by default** (`14:98`, `14:99`). Confirmed for the purchase permission. Customer must also hold Owner on that page. https://learn.microsoft.com/partner-center/customers/give-customers-permission
26. **Savings plans are not offered for pay-as-you-go; they exist for EA, MCA and partner agreements** (`14:99`). Confirmed. https://learn.microsoft.com/azure/cost-management-billing/savings-plan/permission-buy-savings-plan
27. **Who may buy a savings plan** (`14:99`). Partial, and wrong if read as complete. See finding 5. Same URL.
28. **A savings plan cannot be cancelled, refunded or exchanged** (`14:106`). Confirmed in substance. "All savings plan purchases are final. After you buy a savings plan, you can't cancel it or exchange it for a reservation." The page does not use "refunded". Eligible reservations can be traded in for a savings plan; the sentence does not deny that. https://learn.microsoft.com/azure/cost-management-billing/savings-plan/cancel-savings-plan
29. **A reservation or savings plan can be scoped to a resource group, subscription, management group or shared scope. Shared means the EA enrollment, the MCA billing profile, or pay-as-you-go subscriptions created by the account administrator** (`14:104`). Confirmed for reservations, including the pay-as-you-go shared definition. Savings-plan scopes include the same four, and shared means the EA enrollment or MCA billing profile (no pay-as-you-go clause, which fits "not offered"). https://learn.microsoft.com/azure/cost-management-billing/reservations/prepare-buy-reservation and https://learn.microsoft.com/azure/cost-management-billing/savings-plan/scope-savings-plan
30. **MACC is tracked in the portal only for direct EA and direct MCA** (`14:123`). Confirmed for the portal. "MACC functionality in the Azure portal is available only to direct Microsoft Customer Agreement and direct Enterprise Agreement customers." The "REST API only for direct" half is the design's extension of a portal sentence. https://learn.microsoft.com/azure/cost-management-billing/benefits/macc/track-consumption-commitment
31. **Marketplace purchases count toward a MACC only with the "Azure benefit eligible" badge, bought through the Azure portal** (`14:123`). Partial. The badge and the portal checkout are confirmed. Azure services billed through a Marketplace deployment "inherently contribute" without that framing. https://learn.microsoft.com/marketplace/azure-consumption-commitment-benefit
32. **Scope-level Azure Hybrid Benefit: EA and MCA, not CSP-managed customers** (`14:124`). Partial. True for SQL Server centralized management, which is the cited page. Not true as a general Azure Hybrid Benefit statement. See finding 8. https://learn.microsoft.com/azure/cost-management-billing/scope-level/overview-azure-hybrid-benefit-scope
33. **For CSP, only the partner can buy Microsoft Foundry provisioned-throughput reservations** (`14:126`). Confirmed in substance. "only the admin agents or sales agents can purchase". Not the customer, even if general reservation self-service is on. https://learn.microsoft.com/azure/cost-management-billing/reservations/microsoft-foundry
34. **Price sheet sits at enrollment (EA) or billing profile (MCA)** (`14:17`, `14:47`). Confirmed. Exports matrix: "All available prices" is billing account for EA and billing profile for other supported agreements. EA enrollment is that billing account. https://learn.microsoft.com/azure/cost-management-billing/costs/tutorial-improved-exports
35. **Admin agent and billing admin can see partner billing-scope costs** (`14:30`). Confirmed, in the partner tenant. https://learn.microsoft.com/azure/cost-management-billing/costs/get-started-partners
36. **Invoice manager is a real MCA billing role that can download usage files and price sheets** (`14:30`). Confirmed for those downloads. Not checked whether that role sees reservation and savings-plan data. https://learn.microsoft.com/azure/cost-management-billing/manage/understand-mca-roles

Not checked, so not treated as confirmed or wrong: Advisor and Resource Graph role anchors (`14:26`), `managedByTenants` (`14:63`), ARM 250 reads / 25 per second (`05:102`), Azure MCP Server 3.0 generally available (`05:106`), and the 30 September 2028 email retirement (`05:152`).
