## What is strong

- The design correctly rejects prompt-agent BYOM from the critical path, uses hosted agents with accurate runtime limits, and treats PIM/RBAC constraints realistically.
- The Citadel source was read to parameter level: commit, versions, public-network defaults, message capture, retired model allow-list and token-estimation defaults are substantially accurate.
- The retirement register is unusually current; all named dates checked out, subject to the Groundedness product-name correction.
- Flex, SRE Agent, Defender for AI Services, Entra Agent ID licensing, Azure MCP Server 3.0 and MCP 2026-07-28 are correctly represented.
- The design already uses spikes for genuinely environment-specific seams instead of presenting them as settled facts.

## What is missing

1. **A machine-generated platform-status manifest** that reconciles Learn, Release Communications, GitHub releases and pricing meters; a conflict such as Routines must fail closed to preview.
2. **A per-account/per-project service-limit model** covering Foundry's five Cosmos containers per project, session quotas, ACR/network dates, Search limits and total project count.
3. **A package-level Agent Framework bill of materials**: released core is not evidence that hosting, A2A, Harness, FIDES or every integration is GA.
4. **Meter-specific price rules** keyed by model, version, deployment type, region and effective date; no fixed percentage should enter prose or policy.
5. **A gateway capability matrix** separating Citadel Publish preview, native APIM GA server-level governance, preview per-tool control, Foundry's existing-APIM integration and standalone AI Gateway.
