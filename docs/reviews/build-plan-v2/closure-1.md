1. **Budgets only alert; checked every 24 hours; 48 hours for a new subscription** (04:70, 04:90; 01:43; 02:13). `https://learn.microsoft.com/azure/cost-management-billing/costs/tutorial-acm-create-budgets`: "Notifications are triggered when the budget thresholds are exceeded. Supported. Two notes: an action group can start automation (Functions, webhooks) when a threshold is met, which the plan does not use; and `understand-cost-mgt-data` says a budget can be configured at subscription creation, so the tutorial's 48 hours is the stricter reading, which the plan follows.
2. **Cost Details API as a per-resource route, and the role it needs** (01:39, 02:67, 02:72, 03:155). `https://learn.microsoft.com/azure/cost-management-billing/automate/get-small-usage-datasets-on-demand`: the report "is only available for customers with an Enterprise Agreement or Microsoft Customer Agreement"; "you need read only permissions for supported features and scopes"; it "doesn't support management groups"; "query at most once per day. It might include costs from multiple invoices". `https://learn.microsoft.com/azure/cost-management-billing/costs/manage-automation`: "detailed, unaggregated cost data". `https://learn.microsoft.com/azure/cost-management-billing/automate/automation-ingest-usage-details-overview`: cost details are "the most granular cost records ... correlate Azure meter-based charges with the specific resources". `https://learn.microsoft.com/azure/cost-management-billing/costs/understand-work-scopes`: the row "Cost Analysis / Forecast / Query / Cost Details API" is "Read only" for Owner, Contributor, Reader, Cost Management Reader and Cost Management Contributor; "Exports" is create, read, update and delete only for Owner, Contributor and Cost Management Contributor, and read only for Reader and Cost Management Reader.
