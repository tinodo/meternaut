# Technology register

**What this document answers.** Which technologies the design uses, which sit behind a switch, and which it looked at and does not need yet. Each row gives the status and the day it was checked, the decision, and the reason. The last sections list the non-Microsoft components and the platform changes of the past year that shaped the design.

## How to read

Every status is as on **2026-11-01** (**2026-11-02** where a row says so), checked on Microsoft Learn or the vendor's announcement; `UNVERIFIED` marks what could not be confirmed. *Preview* means no service-level agreement; *prerelease* means a package that needs `--pre`. Prices are in [the cost document](10-cost-and-finops.md). Proof points P1 to P10 are in [the roadmap](13-roadmap.md); approval classes R1 to R3 (R1 reversible and small, R2 reversible but larger, R3 irreversible or a purchase) in [security](06-security-and-governance.md).

| Decision | Meaning |
|---|---|
| **Adopt** | In the design now, and generally available |
| **Adopt behind a switch** | Preview, prerelease or licence-bound; off by default; the row names the generally available fallback |
| **Evaluate** | A proof point decides |
| **Not needed in phase 1** | The row says why, and what would change it, or that the service is retiring |
| **Watch** | No role yet; re-check on the event named |

## Platform changes that shaped the design

- **Private networking no longer forces Foundry's data trio:** a bring-your-own-network project can use platform-managed data, so agent state stays in our Cosmos DB. [Learn](https://learn.microsoft.com/azure/foundry/agents/concepts/networking-options)
- **The GPT-6 generation changed price shape:** cache writes bill separately, and aliases absorb it. [Learn](https://learn.microsoft.com/azure/foundry/openai/how-to/prompt-caching)
- **Still preview:** the Copilot harness (2026-10-28) cannot use bring-your-own-model, so it cannot sit behind the hub. [Learn](https://learn.microsoft.com/azure/foundry/agents/concepts/limits-quotas-regions)
