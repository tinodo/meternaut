## 3. Findings that change the design

1. **Foundry workflows retire on 1 December 2026** (rows 734, 767; F8-02). Microsoft's page tells new builders to use Agent Framework, so H1's choice is the only supported path. The Foundry-side human-approval step, long-running and steerable hosted agents and routines are still preview (L35, RC-21): model approval waits with Agent Framework plus the Durable Task extension (F8-03, status unconfirmed), not with a Foundry feature.
2. **"AI gateway" now means three things; H2 must say which.** (a) APIM's AI-gateway capabilities, which "remain available and supported" (L8): Citadel's base. (b) A separate **AI Gateway** product (`Microsoft.ApiManagement/aigateways`), "the primary path for Microsoft's latest AI gateway capabilities", in public preview in East US 2 and Sweden Central only (RC-19 #568184; L8). Its quickstart assumes a publicly accessible Foundry backend and public routing, and networking is read-only after creation (L9): not private-ready, so WATCH. (c) The Foundry portal's AI Gateway wizard creates or reuses an APIM in a **v2 tier in the same tenant and subscription**, is on by default for new projects (L6), and is a Control Plane prerequisite for advanced governance (L4). Risk: a second, Foundry-managed APIM beside the Citadel hub (cost, duplicate policy). Whether a hub in another subscription can satisfy (c): UNVERIFIED; test before relying on Control Plane limit panes.
3. **Bring-your-own-gateway is GA but is now documented as "bring your own model"** (L7): OpenAI-compatible chat-completions endpoints only; API key, managed identity or OAuth. Use a managed identity and `validate-azure-ad-token` at the hub (the page's own example). It serves prompt agents; that hosted agents can call the hub from their own code is our inference (their page says agent code calls the Foundry project endpoint for inference).
4. **"Private networking only" (H3) has three named exceptions.** Teams and Microsoft 365 cannot reach private agents, so a private project needs the source-IP-filtered public Activity route (L26). Foundry Memory has no VNet integration (L11). The AI Gateway preview defaults to public routing (L9). Threat-model the Teams route (Azure Bot Service, Entra authentication, IP filter); keep memory in our own store (H5).
5. **Region choice.** Agents plus private VNet are listed for West Europe, Sweden Central, Germany West Central, France Central and others (L3). Foundry Memory is not offered in West Europe or Germany West Central (L11), and the AI Gateway preview exists in one EU region, Sweden Central (L8). The Foundry resource must sit in the same region as its VNet (L3). Reconcile with A2 and P1 before fixing the primary region.
6. **Entra Agent ID is free; protecting agents is not.** The identity platform is "available for all Microsoft Entra customers", but extending Entra security features to agents (Conditional Access, Identity Protection, governance) requires Microsoft Agent 365: included in Microsoft 365 E7, an add-on to E5/A5/Business Premium (L30). H9 needs a licence decision from the operator; fallback is blueprint + identity + RBAC + Policy. The agent-registry experience is converging under Agent 365 (L29): do not design around a standalone registry.
7. **Claude is not usable by default.** Anthropic is seller, operator and independent data processor; Azure-hosted Claude offers Global Standard and Data Zone Standard (US) only, Anthropic-hosted Global Standard only (L23). No EU data zone: it conflicts with EU residency and Microsoft-only. Exclude it from model-router subsets and the allowed-publisher policy unless the operator accepts the processor.
8. **Model router drifts under a constant version label** (H7/H11). Version `2025-11-18` lists 35 models, one dated 2026-09-03 (L21): the set grew without a version change (our inference from the table). Pin an explicit subset and routing mode; Azure Policy coverage for the router is preview (RC-6).
9. **Always-on meters break H6.** SRE Agent bills 4 AAUs per agent-hour even when idle (L28): 2,920 AAUs per 730-hour month, plus token-based active flow; AAU price UNVERIFIED (P1). Use the 30-day trial (GA 2026-08, RC-8) before committing. Also check Redis stream brokers (F8-03) and Logic App hosts (F8-11).
10. **Safety for tool and agent calls can now live at the hub.** Content safety for MCP and A2A APIs went GA in June 2026, and API Center gained an MCP discovery server (RC-7). The attachment summary for row 736 ("public preview") is wrong: GA since Nov 2025 (RC-1). H2/H8 can enforce safety on tools and agents, not only on model calls.
11. **Foundry-native budgets, tags and auto-pause** (row 799, 2025-11-18; contents in RC-20) attribute cost to deployment, agent and run and can pause on breach: a second line behind per-agent gateway budgets (H7). Make the pause an approved action; it can stop production agents.
12. **Hosted agents are GA with a different architecture from the preview**: microVM per session, session starts under 100 ms from snapshots, suspended between turns, about 20 regions (RC-22); idle timeout 2–240 minutes, sessions deleted after 30 days idle (L2). Contradiction: RC-22 (#563716, June 2026) calls A2A for hosted and prompt agents preview, while L2 (updated 2026-10-27) lists A2A v1.0 as GA and v0.3 as preview; the page wins.
13. **Toolbox (GA June 2026) overlaps Citadel publish contracts** (F8-08). Recommendation, not a finding: keep the hub's publish contracts as the front door for our own tools and use toolboxes only for Foundry-native tools.
14. **Competitive signal.** The Azure Copilot Optimization Agent (preview) covers only VMs and VM Scale Sets, at most 10 items per query, creates no budgets or alerts, and has no documented API (L31). It supports the premise that first-party advice stops at the head of the distribution.
15. **Naming and IaC.** "Azure AI Services" is now "Foundry Tools" (GA 2025-11, RC-22). Foundry roles were renamed (Azure AI User → Foundry User, and likewise Owner, Account Owner, Project Manager); role IDs and permissions are unchanged (L6, L7). Reference role IDs in Bicep and Policy.
16. **Container Apps Sandboxes (GA 2026-09) give the Lab a stateful isolated runtime** (microVM, suspend/resume, egress policy, VNet) that did not exist when the rows were written; dynamic sessions remain the GA fallback. EU regions and prices: UNVERIFIED.
17. **Attachment versus page.** Row 736 (summary "preview", record GA); 780 (named "BYO AI Gateway", now "bring your own model", GA); 801 (title GA, body "public preview for agents", pages show no banner); 772, 768 and 775 (previews, now GA); 734 and 767 (preview, now retiring). In every case the page or record wins.
