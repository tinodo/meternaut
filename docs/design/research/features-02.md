## 3. Findings that change the design

- **Citadel is a set of patterns, not a runtime (F2-18).** The post says there is no separate Citadel runtime and that gateway policies cover only requests routed through the gateway. Anything not explicitly routed through APIM (hosted-agent egress, Foundry-managed tools) sits outside gateway policies, so H2 needs the network design of F2-09 and F2-19 behind it. The repo is now `Azure-Samples/foundry-citadel-platform`, titled "AI Citadel Blueprint" (MIT); A1 should reconcile this with `ai-hub-gateway-solution-accelerator`.
- **A new APIM "AI Gateway tier" (preview) enforces calendar budgets (F2-17).** Cost-limit policies block requests at a budget, with estimated spend per key and model and OTLP export. But the APIM pricing page says "Pricing details are coming soon!" and its link to Citadel's contracts is unverified, so the hub cost model and H7 budgets stay open. Foundry's own AI Gateway (preview) needs Standard v2 or Premium v2 once Foundry is private.
- **Routines replace our scheduler, with hard exclusions (F2-07).** GA, but no workflow agents, **no CMK**, recurrence ≥5 min, 30 s request timeout, five regions excluded. **Contradiction:** Azure Updates entry 563536 still says "In preview" (2026-09-18) while the devblog (2026-09-24) and Learn (2026-10-04) say GA: page wins. If CMK is mandatory, keep a Container Apps job or Functions timer as trigger fallback.
- **Claude cannot meet an EU Data Zone (F2-02).** Azure-hosted Claude is Global Standard or US Data Zone; Anthropic-hosted (incl. Fable 5.1) is Global only and runs outside Azure. Under "assume EU residency", confine Claude to public-document work (Scholar) and keep it out of EU-zoned router subsets.
- **Drift is built into the platform (F2-03, F2-06).** The router pool lost five models in the Jul–Aug 2026 refresh, router versions change, and Standard deployments auto-upgrade. H11's "pinned versions" must set `versionUpgradeOption`, the router version and the subset, and treat a pool change as a release gated by the regression exam. Page lists gpt-4o retiring 2026-10-01: check.
- **Hosted agents are GA, their SDKs are not (F2-08).** AgentServer and Agent Framework hosting packages are pre-release; no traffic split between versions (canary needs separate endpoints or gateway routing); North Europe is not a hosted-agent region; the durable state store can hold Agent Framework checkpoints, which simplifies human-in-the-loop waits.
- **Specialists: skills or A2A? (F2-13).** Moving a specialist's instructions into the orchestrator (Agent Skills over MCP) took a three-pair demo from 15.5 s to 6.3 s, but removes the per-role model choice H7 relies on. Use skills for roles that need only instructions and tools; keep separate A2A agents where a role needs its own model, memory or lifecycle (Detective, Skeptic, Economist).
- **Egress control is preview-only (F2-09).** Use Audit mode as a layer, not a control; the GA control is the agent subnet plus firewall FQDN rules and Citadel-only tool routes.
- **Private-only has two silent failure modes (F2-19).** A private endpoint covers inbound only; and bring-your-own resources without capability hosts silently fall back to Microsoft-managed storage. Add "200 inside, 403 outside" and "BYO stores actually fill" to the spoke acceptance suite, using the Agent Acceptance Gateway pattern (F2-16).
- **A first-party cost-data tool exists (F2-21).** The ARM MCP server offers cost query, forecast, price sheet and benefit recommendations. It is Entra-protected (scope `MCP.Access`; app-only tokens UNVERIFIED) and its optional toolset includes `create_budget`: test it as the Surveyor's cost source through Citadel before building connectors; keep write tools out of the reasoning plane (H4).
- **Microsoft's Optimization Agent is narrow (F2-26).** Preview, VMs and VM Scale Sets only, ten recommendations per query: it confirms the long-tail gap our design targets and is no substitute.
- **SRE Agent is not scale-to-zero (F2-23).** Always-on 4 AAUs per agent-hour from creation until deletion plus token AAUs; the trial waives the always-on part. Keep it optional and off by default (H6, H11).
- **Azure SQL vector indexes are GA (F2-27).** One serverless Azure SQL database could hold Estate Model, Lesson Book and their vectors (H5); test auto-pause behaviour and cost against Cosmos DB and PostgreSQL (A5).
- **Approvals must never be inferred (F2-20).** Independent evidence for H9: a five-agent system inferred consent from chat. Also: no carve-outs in system prompts (one roughly doubled breaches) and a multilingual red-team suite.
- **Cost-model detail (F2-01).** GPT-6.1 Sol bills cache writes ($2.50 vs $2.00 input per M tokens) and EU Data Zone is +20%: P1 and the per-agent token budgets must include both. Tool calling needs the Responses API, so the gateway must proxy it.
- **Voice status differs by source (F2-12).** The attachment summary reads as an availability announcement; the Learn overview marks voice-based agents preview with no SLA: page wins, so the module stays off.
