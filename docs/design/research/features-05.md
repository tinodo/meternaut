## 3. Findings that change the design

- **Hosted agents are GA, with hard edges** (F5-01). H1 holds: per-session microVM sandbox, own Entra agent identity, billing only while a session is active, West Europe and Sweden Central listed. Agent roles must fit 2 vCPU/4 GiB per session and ≤4 h idle, in Python or C#; versions are immutable, with no traffic splitting. The Build blog said "GA in the next 30 days" on the day the record said GA; Learn shows no preview banner, so treat as GA. Likewise incoming A2A was "public preview" at Build, while Learn now lists A2A v1.0 as GA for hosted agents. The Agent Framework itself was called stable for Python and .NET at Build (harness with skills, memory and middleware, Magentic-One orchestration); file-system tools, memory tools and the deep-research agent are preview.
- **Foundry IQ Serverless could let the Atlas index scale to zero** (F5-05), but: preview, billing since 13 Sep 2026, EU regions only Sweden Central, Poland Central and Denmark East (**not West Europe**), 30 indexes of 1 GB, no SLA, inbound private endpoint unconfirmed. Published sample rate: $0.288 per CU-hour and $0.239 per GB-month (West Central US); no EU rate found. West Europe and Sweden Central also carry an AI Search "high demand" footnote that blocks new services: check `fetchOfferings` before choosing a region. GA fallback: Basic (the Free tier has no private endpoint). Per the [serverless cost page](https://learn.microsoft.com/azure/search/serverless-cost-optimization), an index stays active 10 minutes after its last request, so sparse agent calls still bill index compute for that window.
- **Network isolation is a one-way door** (F5-20). Managed VNET is GA but chosen at creation (no disabling, no conversion from a custom VNet), and its FQDN rules create a managed Azure Firewall whose charges the "free" feature hides. The AI Landing Zone's bring-your-own-VNet route is the alternative: an operator decision (H3, cost).
- **Gateway routing for agents is supported but shaped.** Bring-your-own-model is GA (Apr 2026, [RC 561002](https://www.microsoft.com/releasecommunications/api/v2/azure/561002)), but the [Learn page](https://learn.microsoft.com/en-us/azure/foundry/agents/how-to/ai-gateway?tabs=api-management&pivots=foundry-portal) calls such models "Non-Microsoft Products" with responsible-AI and data handling on you, describes prompt agents only, uses Chat Completions, and excludes the Copilot harness. The [Unified Model API page](https://learn.microsoft.com/en-us/azure/api-management/unified-model-api) (preview) is Chat-Completions-only too, so agents on the Responses API cannot use aliases. How hosted agents are routed through APIM: UNVERIFIED (A1/A2).
- **Gateway safety now spans MCP and A2A** (F5-09): content safety GA on MCP and A2A, A2A APIs GA in classic and v2 tiers, token metrics for cached and reasoning tokens in preview (cost attribution, F5-08). New APIM features reach v2 tiers and the classic "AI release channel" first: check our tier.
- **Deterministic agent controls exist, all young** (F5-17/18/19): FIDES (experimental), AGT (MIT, public preview, breaking v4), ACS and ASSERT (new). They give H8 a non-LLM layer: label untrusted text, check every tool call. AGT's DID identity duplicates Entra Agent ID: take the policy and circuit-breaker parts only.
- **Scheduling and identity may now be platform features** (F5-37/38): routines (preview) run a hosted agent on a schedule, possibly replacing an external scheduler for the Watch and Learning clocks; autopilot agents (preview) give an agent an Entra Agent ID, mailbox and Teams presence through Agent 365: a ready home for the Diplomat, licensing unknown.
- **RBAC changed shape** (F5-16): renamed roles (IDs unchanged), a least-privilege **Foundry Agent Consumer**, and agent-scope assignments. Reference role IDs in Bicep and Policy; disable keys, which bypass RBAC.
- **Evaluation can run privately and on sampled production traces** (F5-15, F5-39): this removes "evals need public endpoints" as an objection to H3 and gives H11 a platform signal source; the independent Exam remains ours.
- **Procedural memory (preview) overlaps our "learned policy"** (F5-02): vendor-reported +7–14% on Tau-bench, but opaque. A candidate only; test it on the Exam; the Lesson Book stays ours. The open STATE-Bench measures whether memory helps.
- **A service can call a model around the gateway** (F5-24): Cosmos integrated embeddings use the Cosmos account's identity against a Foundry endpoint; AI Search skillsets do the same (F5-07). Check each can target the gateway, or accept the bypass.
- **Retirement:** AI Services Metrics Advisor was retired on 18 May 2026 (the record's slug says 1 Oct 2026). Spend-anomaly detection for the Watch clock should use KQL anomaly functions or the open-source detector, not an AI-service detector (F5-35).
- **Voice has two paths** (F5-03): Voice Live with an agent is GA, but Learn (5 Oct 2026) steers new work to Foundry voice agents (preview, speech-to-speech, lower latency). Specify the module on the GA path, with the preview path behind a switch.
- **Token limits bite early** (F5-21): Foundry rate limiting counts `max_tokens` at request time, so contract budgets must set it deliberately or agents throttle themselves at low usage. Quota is GA for Global and Data Zone Standard.
- **Classic agents are being replaced:** the [migration guide](https://learn.microsoft.com/azure/foundry/agents/how-to/migrate) (updated 6 Oct 2026) moves classic agents and the Assistants API to the new Agent Service (conversations and responses). Build only on the new API; the retirement date was not found.
