## 3. Findings that change the design

1. **A second gateway product exists, is "the primary path", and is preview and unpriced.** `Microsoft.ApiManagement/aigateways` is preview in East US 2 and Sweden Central only, with no SLA; the APIM pricing page of 31 Oct says "Pricing details are coming soon!". Learn (28 Oct) says APIM-service AI features "remain available and supported". H2 stays on APIM v2 for phase 1; keep contracts as data so they can later render into AI Gateway JSON policies; spike it in Sweden Central. ([Learn compare](https://learn.microsoft.com/azure/ai-gateway/compare-api-management-service), [APIM pricing](https://azure.microsoft.com/en-us/pricing/details/api-management/))
2. **Networking gotcha: Foundry's gateway console cannot use a central hub.** "Use existing APIM" lists only v2 instances in the same tenant and subscription as the Foundry resource; "Create new" builds Basic v2 without VNet support. A Citadel hub in a platform subscription must connect through bring-your-own-model connections (GA Apr 2026), not the console. ([Learn how-to](https://learn.microsoft.com/azure/foundry/configuration/enable-ai-api-management-gateway-portal), [Azure Updates 561002](https://www.microsoft.com/releasecommunications/api/v2/azure/561002), [APIM pricing](https://azure.microsoft.com/en-us/pricing/details/api-management/))
3. **Governance small print (ask A1/A3).** The BYOM page calls BYOM models Non-Microsoft Products: you own content filters and data handling, and BYOM is unsupported with the Copilot harness. If Azure-sold models behind an APIM connection count as BYOM, Foundry guardrails (H8, layer one) may not apply and gateway content safety carries the load. ([Learn BYOM](https://learn.microsoft.com/en-us/azure/foundry/agents/how-to/ai-gateway?tabs=api-management&pivots=foundry-portal))
4. **EU residency breaks for some models.** Claude "Hosted on Azure" offers Global Standard and **US** Data Zone Standard only (17 Aug). In the September digest GPT-6 Astra has Data Zone Standard in the US only, GPT-6.1 Sol in Europe too (21 regions), GPT-6 Luna in US and Europe (16). Limit the reasoning tier to models with an EU Data Zone; treat Claude as an explicit exception. ([Claude devblog](https://devblogs.microsoft.com/foundry/five-new-claude-capabilities-now-available-in-foundry/), [Sep digest](https://devblogs.microsoft.com/foundry/whats-new-in-microsoft-foundry-september-2026/))
5. **The model router drifts by design (H11).** Its pool refreshes without redeployment (GPT-5.6 family and Claude Opus 4.8 added; gpt-5-chat variants and DeepSeek-V3.1 removed); September adds preview session affinity and routing metadata and 32 regions including North Europe. Gate every refresh with an Exam run, log the chosen model, use affinity for cache reuse. ([TC 4521310](https://techcommunity.microsoft.com/t5/microsoft-foundry-blog/model-router-updates-new-regions-a-refreshed-model-pool-and/ba-p/4521310), [Sep digest](https://devblogs.microsoft.com/foundry/whats-new-in-microsoft-foundry-september-2026/))
6. **Cost tools now exist as MCP servers.** The ARM MCP server's Cost Management and Pricing toolsets (query, forecast, budgets, Advisor, reservations, price sheets) and Azure MCP Server 3.0 (GA Oct 2026, Advisor cost tools) cover ad-hoc queries. Exclude `create_budget` for read-only identities (H4); status and non-interactive auth of the ARM server are unverified. ([TC 4530710](https://techcommunity.microsoft.com/t5/finops-blog/introducing-cost-management-and-pricing-toolsets-in-azure/ba-p/4530710), [Azure Updates 578662](https://www.microsoft.com/releasecommunications/api/v2/azure/578662))
7. **Meter naming is a trap in our own AI bill.** First-party model meters sit under "Foundry Models", Claude under SaaS/Other, token type only inside the meter name; "Azure SRE Agent Unit" and the Observability Agent's "Azure Agent Credits" (500 per operation, billed since 1 Jul) are separate agent meters. The Atlas needs these as claims; our reports need a meter map on `x_SkuMeterId`. ([TC 4547978](https://techcommunity.microsoft.com/t5/finops-blog/who-ordered-all-these-tokens-giving-ai-spend-a-name-in-focus/ba-p/4547978), [TC 4537780](https://techcommunity.microsoft.com/t5/azure-observability-blog/understanding-billing-for-the-azure-copilot-observability-agent/ba-p/4537780))
8. **H1 is GA-backed.** Orchestrations 1.0 (8 Jul), declarative YAML workflows 1.0 with human approval and checkpoint/resume (23 Jul), Harness and skills stable, Hosted Agents GA (9 Jul), Toolboxes GA. Still preview or experimental: Foundry tracing for Agent Framework, DevUI, CodeAct/Hyperlight, episodic memory, MCP-hosted skills. Build on GA; put previews behind switches. ([Orchestrations](https://devblogs.microsoft.com/agent-framework/agent-frameworks-orchestration-patterns-reach-1-0/), [Declarative](https://devblogs.microsoft.com/agent-framework/move-agent-orchestration-workflows-out-of-code-with-agent-framework-declarative-workflows-1-0/), [Jul–Aug digest](https://devblogs.microsoft.com/foundry/whats-new-in-microsoft-foundry-july-august-2026/))
9. **A deterministic action gate now exists (H4).** AGT (MIT, public preview) intercepts tool calls, messages and delegations and enforces allow, deny or require-approval with tamper-evident audit; the engine is ACS. Candidate gate in front of the Move runner. Breaking v4→v5 changes: pin versions. It complements Citadel, it does not replace it. ([AGT repo](https://github.com/microsoft/agent-governance-toolkit))
10. **Previews age fast; the attachment lags.** ACA Sandboxes went GA on 23 Sep although the Aug post and the attachment say preview; HorizonDB is still preview (regions expanded 5 Oct); the AI Gateway is still preview. Re-check each preview on its Azure Updates entry before it enters the design. ([Azure Updates 561262](https://www.microsoft.com/releasecommunications/api/v2/azure/561262), [Azure Updates 572940](https://www.microsoft.com/releasecommunications/api/v2/azure/572940))
11. **Contradiction: Foundry Routines.** Azure Updates 563536 (modified 18 Sep) says In preview, not covered by production SLAs; the Foundry digest of 15 Oct says GA. Treat as unconfirmed. If GA, Routines replace Logic Apps or Functions glue on the Watch clock. ([Azure Updates 563536](https://www.microsoft.com/releasecommunications/api/v2/azure/563536), [Sep digest](https://devblogs.microsoft.com/foundry/whats-new-in-microsoft-foundry-september-2026/))
12. **Names drift: pin identifiers, not marketing names.** "Serverless Agents" is now "Azure Functions hosted skills" (preview, Python v2 apps); one Azure Updates entry calls Agent Framework "Microsoft Foundry Agent Framework"; Foundry RBAC roles were renamed (Foundry User, Owner, Account Owner, Project Manager; role IDs unchanged). Update IaC and docs. ([Learn hosted skills](https://learn.microsoft.com/azure/azure-functions/functions-hosted-skills), [Azure Updates 564312](https://www.microsoft.com/releasecommunications/api/v2/azure/564312))
13. **Trace privacy is now configurable (H8/H9).** The preview GenAIContent table restricts who reads prompts, responses and tool calls; the Observability Agent (GA) now reads Basic and Auxiliary table plans, so cheap log plans stay investigable. Adopt behind a switch; fallback: capture no content. ([Azure Updates 567594](https://www.microsoft.com/releasecommunications/api/v2/azure/567594), [Azure Updates 570250](https://www.microsoft.com/releasecommunications/api/v2/azure/570250))
14. **Copilot-owned loops bypass the gateway.** In the GitHub Copilot agent for Agent Framework, Copilot owns model calls and planning: keep it out of the reasoning plane unless BYOK through the gateway is confirmed. ([Devblog 4 Aug](https://devblogs.microsoft.com/agent-framework/build-production-ready-agents-with-the-github-copilot-harness-and-agent-framework/))
15. **Teams path is simpler than assumed, but autopilot agents cost a licence (H10).** Publishing to Teams and Microsoft 365 Copilot is GA (10 Jun) and hosted agents can expose an Activity protocol for Teams messages and card actions. Autopilot agents need their own Entra Agent ID user with a productivity licence: prefer a hosted agent over an autopilot agent unless the licence cost is accepted. ([June recap](https://devblogs.microsoft.com/foundry/whats-new-in-microsoft-foundry-june-2026/), [Sep digest](https://devblogs.microsoft.com/foundry/whats-new-in-microsoft-foundry-september-2026/))
16. **MCP: durability and delegation are not free.** MCP Tasks return a handle but the server must supply a state store and queue; EMA is a stable extension, yet Entra plus App Service gives governed OAuth, not native EMA (no ID-JAG). Use the Toolbox agentic-identity auth type for per-agent audit; keep human approvals in our own append-only record, not `tasks/update`. ([TC 4545170](https://techcommunity.microsoft.com/t5/apps-on-azure-blog/build-durable-long-running-mcp-tasks-on-azure-app-service/ba-p/4545170), [TC 4537433](https://techcommunity.microsoft.com/t5/apps-on-azure-blog/mcp-enterprise-authorization-is-here-what-entra-and-app-service/ba-p/4537433))
17. **KPI for H7.** Use "cost per accepted task", not token price, as the Auditor's cost KPI; one cited study saw up to 30x token-cost spread for the same task, so per-agent budgets in contracts need hard caps. ([TC 4540472](https://techcommunity.microsoft.com/t5/azure-architecture-blog/token-economics-in-practice/ba-p/4540472))
18. **Azure Copilot agents are on by default** for users with Azure Copilot access (Aug 2026); set the tenant switch deliberately and benchmark the Optimization agent as a baseline on the Exam. ([Azure Updates 569685](https://www.microsoft.com/releasecommunications/api/v2/azure/569685))
