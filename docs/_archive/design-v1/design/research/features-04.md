## 3. Findings that change the design

- **MCP 2026-07-28 is a breaking, stateless revision** (F4-08, F4-03): no `initialize`, no `Mcp-Session-Id`, routable `Mcp-Method`/`Mcp-Name` headers, cacheable `tools/list`, trace context in `_meta`, a Tasks extension. Microsoft's SQL MCP Server docs (updated 2026-05-15) fix `2025-06-18` as the default. Keep a protocol-version matrix per hop (agent client, Toolbox, APIM, server) and 2025-11-25 as fallback until each hop is tested.
- **Serverless AI Search gives scale-to-zero but not private-only** (F4-33, F4-15): preview consumption pricing (CU/h plus GB-month; billed since 2026-09-13), EU regions Denmark East, Poland Central and Sweden Central only (not West or North Europe), no Shared Private Link and no private networking for indexers, while the GA private route (F4-15) needs a dedicated tier. H3 and H6 collide for retrieval: decide per environment; fallback Free or Basic dedicated.
- **AI Search's own model calls can bypass Citadel** (F4-16): embeddings, the GenAI Prompt skill and the vectorizer call models directly; only the preview "APIM support for Foundry models in AI Search" routes them through APIM. Without it, H2's budgets and attribution leak.
- **Teams publishing clashes with "private networking only"** (F4-30): portal publishing is unsupported when public network access is disabled; the REST route needs `enable_m365_public_endpoint`, a source-IP-filtered public Activity route (Azure Bot Service and Microsoft 365 ranges). Treat it as a documented, narrow ingress exception for H3/H10; compare A3's Agents SDK route.
- **Hosted agents are GA (2026-06) and Agent Framework is 1.0 (2026-04-02)** (F4-32, F4-25): together they supply H1, H6 and H9 (agent identity assigned at deploy, scale to zero, BYO VNet). A devblog says hosted agents run with default-deny egress (F4-11): every tool, gateway and Graph endpoint needs an explicit allow; confirm in A2.
- **Foundry Routines (preview) can drive the Watch clock** (F4-31): schedule or event triggers invoke an agent with run history in the project; multi-step Cases stay in workflows ("use a workflow instead"). Fallback: Container Apps jobs or Functions timers.
- **APIM MCP management is GA, so per-tool allowlists belong in the access contract** (F4-12): MCP servers join products, with tool-level observability, side-by-side versions and Bicep; a static `tools/list` + `tools/call` allowlist is the deterministic default, the dynamic deny-list rewrites the response body.
- **Toolbox (GA) is a second governance plane next to APIM** (F4-04): one MCP endpoint per bundle with central auth, guardrails and tool search. Promoting its default version re-points every consumer at once (clashes with H11's pinned versions unless promotion is a gated release); the Toolbox-to-Citadel traffic path is undocumented in the pages read.
- **The ARM MCP Server cannot serve the reasoning plane** (F4-10): it runs only as the signed-in user and its write half deploys templates with the human's rights. Copy its *determinism contract* for Detectors instead: queries from a versioned file (never LLM-written at run time), validate then execute, frozen output templates, run IDs derived from the rule hash.
- **Long-running work needs start/poll tools today** (F4-02): client timeouts are about 30–60 s and Tasks support is not broad yet, so Lab experiments and Moves are explicit-handle start/poll pairs with the handle bound to the caller.
- **Agent threat protection moved to an Agent 365 licence** (F4-21): since 2026-07-01 Foundry agent security formerly in Defender for Cloud needs an Agent 365-eligible licence and moves to the Defender portal and the Microsoft 365 agent registry. Re-price the SEC layer (A4).
- **Learning-loop previews produce candidates, not truth** (F4-11, F4-26, F4-29): agent optimizer, rubric evaluators with trace sampling, and procedural memory are all preview and rewrite or extract what we pin. Route outputs through the regression exam and human review; trace sampling is a cost lever; STATE-Bench is a ready yardstick for "improves with experience".
- **CodeAct may cut tokens** (F4-05): on the vendor's own workload it cut time by 52.4% and tokens by 63.9%, but the package is alpha: test on Detective and Economist loops.
- **A2A has two governance paths** (F4-28): Foundry-managed A2A (identity, content safety, audit per hop; v1.0 GA per the Learn overview) versus Citadel A2A publish contracts; whether managed traffic traverses APIM is undocumented.
- **Price platform-operations agents before adopting them** (F4-09, F4-13): the Observability Agent bills Azure Agent Credits since 2026-07-01 (300 AAC cap per deep investigation, user identity, West Europe the only EU region, no customer-managed keys for conversations); SRE Agent runs as a managed identity, "agent identity next", VNet integration in preview.
- **Smaller controls and savings**: OpenTelemetry direct ingest is GA (F4-20); ACA Sandboxes (preview) give scale-to-zero, default-deny disposable compute (F4-18); the MIT-licensed Agent Governance Toolkit (public preview) adds deterministic in-process policy, so adopt it only if it closes a gap APIM and Toolbox leave (F4-19).
- **Cross-slice pointer:** an Azure Updates API title search surfaced "Public Preview: Serverless agents runtime for Azure Functions" (RCAPI:562482, 2026-06); it is outside this slice and was not read: A5 and the owner of that slice should check it against hosted agents.
