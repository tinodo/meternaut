## 3. Findings that change the design

- **Agent Framework is GA; the ecosystem around it is mixed (H1, H11).** Python 1.0.0 on 2026-04-02, 1.24.0 on 2026-10-30. `released`: core, foundry, openai, orchestrations, declarative, ag-ui, github-copilot. `beta`: a2a, azure-ai-search, azure-cosmos, devui, foundry-hosting, purview, claude. Experimental features: Harness, evals, declarative-agent loading, FIDES, functional workflows, session store. This table is Python: on .NET the Foundry package still installs with `--prerelease` (https://learn.microsoft.com/agent-framework/overview/, 2026-10-28). Phase 1 builds on `released` surfaces, wraps beta ones behind adapters, pins every package. Watch FIDES (security labels, content indirection, a secure MCP proxy) for H8's "external text is data" (F7-12, F7-13).
- **Durable human-in-the-loop has two first-party paths, both pre-GA (H1, H4).** The Durable Extension for Agent Framework persists sessions, checkpoints workflows and waits for human input without compute or tokens (Functions Flex scale to zero, or your own workers with Durable Task Scheduler; prerelease packages). Foundry's long-running hosted agents suspend and resume under one task id for days (preview, Learn Aug 2026). Test both against plain MAF checkpoints for the two-approver purchase flow (F7-16).
- **Azure SRE Agent breaks scale-to-zero (H6, H11).** 4 AAU per agent-hour always-on, €0.0968 per AAU in Sweden Central and €0.1197 in West and North Europe ⇒ about €280–350 per agent-month before tokens. "Stop" keeps the charge; only deletion ends it. Our own watchers cover "the system watches its own estate" (F7-14).
- **Claude has no EU Data Zone option today (H7, EU residency).** The partner-models page lists Claude under Data Zone Standard for the Americas only; its Europe tab says not available. Claude for Detective or Skeptic means Global Standard processing, a Marketplace subscription, and no CSP subscriptions (F7-15).
- **Model router's version id does not pin behaviour (H7, H11).** Version 2025-11-18 gains underlying models without changing its identifier; older versions are frozen. Pin with a model subset plus a per-role regression exam (F7-27).
- **Prompt agents reach Citadel through "bring your own model", and guardrail coverage is unstated (H2, H8).** Auth is an APIM subscription key, gateway key or OAuth client credentials; unsupported with the Microsoft Copilot harness; hosted-agent behaviour and Foundry-guardrail coverage of gateway-routed calls are not stated. Treat gateway content-safety policy as the enforcement point. The how-to carries no label while APIM's page calls the Foundry integration preview. APIM also ships a "unified model API (preview)": weigh it against Citadel's custom policies (F7-22, F7-23).
- **Hosted agents now fit the private, scale-to-zero shape (H1, H3, H6), with a region catch.** Per-session VM-isolated sandboxes, idle timeout 2–240 minutes, per-agent Entra identity, private ACR only for projects created after 2026-06-25. Learn lists West Europe and Sweden Central, but the Retail Prices API has hosted meters for Sweden Central (€0.0962 per vCPU-hour, €0.0114 per GiB-hour) and none for West Europe. Prompt agents carry no hosting charge, only tokens. The core label is not stated; the long-running features are preview (F7-07, F7-10).
- **Foundry memory is for people, not for claims (H5).** Preview; user-profile, chat-summary and procedural memories with TTL and forget commands. Automatic consolidation cannot carry receipts, so Estate Model and Lesson Book stay in our store (F7-24).
- **Agent Skills (`SKILL.md`) is a ready container for the Commons.** About 100 tokens advertised per skill, under 5,000 on load; the same folder works in Agent Framework, Copilot and Claude Code; the Cosmos DB Agent Kit (45+ rules) is a precedent. Scripts need approval gating (F7-11, F7-33).
- **Tool count costs tokens (H2, H7).** AKS MCP cut tools by 30%; DAB serves a database through five; skills disclose progressively. Keep published MCP tools few and schema-driven; count their tokens in each agent's budget (F7-19).
- **Experiments need opaque run codes (TEST, LAB).** Free-text parameters were followed 68.4% of the time over 1,135 calls; a server-resolved code word reached 100%. The Experimenter should pass codes, not parameters (F7-28).
- **The Scholar has keyless first-party feeds for Azure changes (STUDY).** The Release Communications MCP server (`microsoft.com/releasecommunications/mcp`; no authentication or licence; API terms apply) and the JSON API behind Azure Updates give machine access; API records carry status, GA or preview month and tags such as Retirements. The Updates web pages are JavaScript-only: do not scrape them (https://learn.microsoft.com/en-us/microsoft-365/admin/manage/mrc-mcp?view=o365-worldwide).
- **Cheap stores to compare for H5 and H9 (A4, A5).** Azure SQL free tier: 100,000 vCore-seconds and 32 GB per month per database, up to 10 per subscription (F7-34). Confidential ledger has a floor of about €103 per month (Standard instance) or €289 (Managed CCF, 3 nodes) in West Europe: dear for an approvals record (F7-36).
- **Gotchas for IaC and SDKs (H12).** Foundry RBAC roles were renamed (Azure AI User → Foundry User, and so on; role IDs unchanged): reference role IDs. `azure-ai-agents` is superseded by `azure-ai-projects` 2.x; the `/openai/v1` prefix is not a Foundry version; the `azd ai agent` extension was pre-1.0 in March: keep Bicep as the source of truth. Retired in this slice and unused by us: AzureML SDK v1 (2026-06-30) (F7-05, F7-06, F7-35).
