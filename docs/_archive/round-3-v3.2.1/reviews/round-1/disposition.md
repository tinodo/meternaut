## 6. Qualifications and corrections — in full

1. **R12 / F7 — LAQueryLogs coverage.** Reviewer A cited the Azure Monitor *Query audit* page, which lists `M365D_AdvancedHunting`, Sentinel investigation clients and the Sentinel portal as request client apps. The orchestrator re-read it **and** the Sentinel documentation: the Sentinel page says hunting and the Investigation Graph are *excluded*. The two pages **contradict each other**; both agree that **scheduled alert executions are not logged**. So the reviewer's *conclusion* (do not hard-code an exclusion list) is right, but "the v1 claim is stale" is too strong. Fix applied: measure coverage per workspace with a canary query.
2. **F12 — model retirement.** Reviewer C wrote that some Foundry models retire "with no deprecation period". The orchestrator found the Learn statement "at least 60 days' notice before model retirement for GA models" (and at least 30 days for preview upgrades). The claim is overstated; version pinning is still time-limited, so the reworded principle and the R23 mitigation stand.
3. **F1 — what exists.** All three first-party facts were confirmed against primary sources (Defender governance rules, SRE Agent Review mode, Sentinel SOC optimization), with scope notes: Defender governance needs Defender CSPM and covers *security* recommendations; only SRE Agent Administrators approve; SOC optimization covers Sentinel workspaces over a 30-day window and the Azure-portal Sentinel experience retires after 31 March 2027.
4. **F3 — thresholds.** K1–K7 are the reviewer's strawman. They are recorded as a strawman and the operator sets the numbers (D11).
5. **F11 — employer policy.** Whether a Microsoft employee may build and publish consumption-reducing software is a matter of internal policy that nobody involved can see from here; it is an operator decision (D13), not something this package can answer.
6. **R1 — wording.** The reviewer's description (1–3 scale units → 500 connections, 4–6 → 1,000, 7–10 → 5,000) was re-verified against the Virtual WAN FAQ; the table also continues to 11–20 → 10,000 and +10,000 per additional pair of instances, which v2 records in full.
7. **Probabilities.** Reviewer C's 12-month odds are judgement, not fact; they appear in [research/06 §4](../../research/06-first-party-teardown.md) labelled as such.
8. **Regulatory points.** No GDPR, EU AI Act or works-council conclusion was relied on by any reviewer; all remain flagged for counsel.
